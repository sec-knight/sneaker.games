# Admin Lobby

Three.js dungeon lobby for the studio mascots. Built from the KayKit Dungeon Asset Pack (Google Drive) with Sneaker, Nezuko, and Midnight from `assets/models/*.min.glb` and the shared UAL1 animation library.

## Assets

Dungeon props ship in `assets/dungeon/`:

- `Dungeon-AssetPack.fbx` — KayKit modular dungeon mesh library
- `Assets-textures.png` — atlas texture

Character models and UAL1 clips live in the site-wide `assets/models/` folder.

## Rebuild dungeon assets

If you replace the dungeon pack on Drive, download `Dungeon-AssetPack.fbx` and `Assets-textures.png` from the **Dungeon Asset Pack** folder into `admin/lobby/assets/dungeon/`.

## Local preview

Serve the repo root (same as other admin tools) and open `/admin/lobby/`.

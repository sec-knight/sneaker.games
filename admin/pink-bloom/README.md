Private playable build of the Pink Bloom night-shift survival looter — a seeded Lightyear City with cars, a cave, and skeletons, built in Three.js from a mixed asset vault.

- URL: `https://sneaker.games/admin/pink-bloom/`
- Access: Cloudflare Access on `/admin/*`
- Source: `sec-knight/cursed-procedure` (`npm run build:admin`)

Rebuild from that repo with:

```bash
npm run build:admin
```

Then copy `deploy/sneaker-admin/pink-bloom/` over this folder.

# Intent

sneaker.games is Mark's personal project hub: a small public studio site and a private workshop on the same domain.

The public face is a home for playable experiments, workshop writing, and morning-wisdom essays. The private face is an Access-protected admin workshop for prototypes, playtests, and tools that should not be linked from the public site.

This repository is the live website and the architecture repo for that hub. Game and tool source that is too large, too messy, or on a different lifecycle lives in `extra_sources` and is copied here as deployable bundles.

Keep the site small. Do not invent games, routes, or hosting pieces that are not already in the tree.
